# 🚗 RoadGuardian — Driver Monitoring System & ADAS Road Perception

> **AI-Powered Local Vehicle Safety Intelligence Platform**
> Dual-Camera Architecture: Real-Time Driver Monitoring System (DMS) + Advanced Road Perception & Collision Avoidance (ADAS) + Black Box Event Data Recorder (EDR) + Connected Vehicle Witness Discovery.
> Runs 100% locally · No cloud required · One command to start.

## 🚀 Quick Start (For Git Users)

### 1. Clone the repository
```bash
git clone https://github.com/KRISH141006/infinity_hacks.git
cd "infinity_hacks/driver-monitor"
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch with One Command
```bash
python run.py
```
> This checks for required models (auto-downloading if missing) and launches the interactive dashboard at **http://localhost:8501**.

## 🧠 Feature Highlights

### 1. 📹 Internal Camera (DMS — Driver Monitoring System)
- **Facial Landmark Tracking**: 478 MediaPipe 3D face mesh points + real-time iris tracking.
- **Drowsiness Detection**: Eye Aspect Ratio (EAR), PERCLOS, Blink Rate, and Mouth Aspect Ratio (MAR for yawning).
- **Distraction & Gaze Analysis**: 3-axis head pose (Yaw, Pitch, Roll) fused with iris gaze tracking.
- **Phone Usage Detection**: Real-time object detection for mobile devices while driving.

### 2. 🛣️ External Camera (ADAS — Road Perception & Collision Avoidance)
- **Object Detection & Tracking**: Persistent ID tracking for cars, trucks, buses, motorcycles, bicycles, and pedestrians.
- **Homography Distance Estimation**: Ground plane horizon projection for distance measurement.
- **Time-To-Collision (TTC) & Looming Rate**: Identifies high-velocity approach speeds and imminent crash risks.
- **Advanced Lane Detection & Departure Warning**: Perspective warping + HLS/Sobel gradient filtering with 2nd-order polynomial lane corridor fitting.
- **Road Hazard Alert**: Detects stationary obstacles directly inside the vehicle's driving path.

### 3. 📦 RoadGuardian Black Box (EDR) & Geofence Witness Discovery
- **Incident Data Recorder**: Locks a 26-frame window (15 pre-event, 1 trigger, 10 post-event) upon sudden deceleration or collision risk.
- **Witness Finder**: Simulates a GPS geofence query to discover nearby connected vehicles with overlapping dashcam caches for accident investigation.
