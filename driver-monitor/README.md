# 🚗 RoadGuardian — Driver Monitoring System

> AI-powered, fully local Driver Monitoring System + RoadGuardian Event Data Recorder.
> Runs on MacBook M4 Air · No cloud required · One command to start.

---

## 📁 Project Structure

```
driver-monitor/
│
├── 📄 dashboard.py              ← Streamlit cockpit UI (main entry point)
├── 📄 process_video.py          ← CLI tool — processes driver video end-to-end
├── 📄 run.py                    ← Convenience launcher
├── 📄 requirements.txt          ← Python dependencies
│
├── 📂 src/                      ← DMS core pipeline modules
│   ├── attention.py             ← Distraction scorer + gaze/pose fusion
│   ├── blackbox.py              ← RoadGuardian EDR + Random Forest inference
│   ├── drowsiness.py            ← EAR / PERCLOS / blink / yawn engine
│   ├── face_landmarks.py        ← MediaPipe Face Landmarker wrapper
│   ├── gaze.py                  ← Iris-based gaze tracker
│   ├── head_pose.py             ← 3-axis head pose estimator
│   ├── phone_detection.py       ← YOLO phone detector
│   └── video_processor.py       ← Frame-by-frame orchestrator
│
├── 📂 models/                   ← Pre-trained model weights
│   ├── face_landmarker.task     ← MediaPipe face landmarker model
│   ├── yolo11n.pt               ← YOLO v11 nano (phone detection)
│   ├── 📂 drowsiness_model/     ← YOLO drowsiness classification model
│   └── 📂 roadguardian/         ← RoadGuardian Random Forest models
│       ├── roadguardian_event_status_rf_v2.pkl   ← Predicts NORMAL/WARNING/CRITICAL
│       └── roadguardian_event_type_rf_v1.pkl     ← Predicts event type (COLLISION etc.)
│
├── 📂 training/                 ← Model training scripts & datasets
│   ├── train_roadguardian.py    ← Converted from blackbox.ipynb (run to retrain)

│
├── 📂 input/                    ← Driver-facing video inputs
│   └── (place your .mp4 files here)
│
└── 📂 output/                   ← Auto-generated by the pipeline
```

## 🚀 Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Process a driver video
```bash
python process_video.py --input input/your_video.mp4
```
> This will run MediaPipe, YOLO, RoadGuardian classifiers, and transcode the output automatically.

### 3. Launch the dashboard
```bash
streamlit run dashboard.py
```
> Open http://localhost:8501 in your browser.

## 🧠 Pipeline Overview

```
Driver Video
     ↓
OpenCV (frame-by-frame)
     ↓
MediaPipe Face Landmarker
     ↓
 ┌───────────────────────────────┐
 │  Feature Extraction            │
 │  ├── EAR (Eye Aspect Ratio)    │
 │  ├── PERCLOS                   │
 │  ├── Blink Rate                │
 │  ├── MAR (Mouth — Yawn)        │
 │  ├── Head Pose (Yaw/Pitch/Roll)│
 │  └── Gaze Direction (Iris)     │
 └───────────────────────────────┘
     ↓
 ┌───────────────────────────────┐
 │  ML Classifiers                │
 │  ├── YOLO: Drowsiness          │
 │  ├── YOLO: Phone Detection     │
 │  ├── RF:   Event Status        │  ← RoadGuardian
 │  └── RF:   Event Type          │  ← RoadGuardian
 └───────────────────────────────┘
     ↓
Telemetry + Alerts + Black Box EDR
     ↓
RoadGuardian Cockpit Dashboard
```

## 🏋️ Retrain RoadGuardian Models

To retrain the event classifiers from scratch using the included dataset:
```bash
python training/train_roadguardian.py
```
Trained models are saved automatically to `models/roadguardian/`.

## 📦 RoadGuardian Event Data Recorder (Black Box)

When a **CRITICAL** event is detected during video processing:
- ✅ **15 pre-event** frames are preserved from the rolling buffer
- ✅ **1 event** frame is locked at point of detection
- ✅ **10 post-event** frames are collected as aftermath
- ✅ Exported to `output/roadguardian_blackbox_event.csv`
- ✅ Summary saved to `output/roadguardian_incident_summary.json`
- ✅ Downloadable directly from the Cockpit Dashboard
