driver-monitor/

│   │   ├── config.py               ← Camera calibration & ADAS thresholds
│   │   ├── distance_estimator.py   ← Homography pitch-horizon distance calculation
│   │   ├── lane_detection.py       ← Polynomial lane fitting & departure warning
│   │   ├── road_processor.py       ← Full labeled video generator & tracker
│   │   ├── video_recorder.py       ← Pre/post accident incident rolling buffer
│   │   └── witness_finder.py       ← Geofence connected vehicle witness discovery
│   │
│   ├── attention.py             ← Distraction scorer + gaze/pose fusion
│   ├── blackbox.py              ← RoadGuardian EDR + Random Forest inference
│   ├── drowsiness.py            ← EAR / PERCLOS / blink / yawn engine
│   ├── face_landmarks.py        ← MediaPipe Face Landmarker wrapper
│   ├── gaze.py                  ← Iris-based gaze tracker
│   ├── head_pose.py             ← 3-axis head pose estimator
│   ├── phone_detection.py       ← YOLO phone detector
│   └── video_processor.py       ← Driver video frame-by-frame orchestrator
│
├── 📂 models/                   ← Pre-trained model weights
│   ├── face_landmarker.task     ← MediaPipe face landmarker model
│   ├── yolo11n.pt               ← YOLO v11 nano (phone & driver detection)
│   ├── yolov8m.pt               ← YOLO v8 medium (ADAS road targets tracking)
│   ├── 📂 drowsiness_model/     ← YOLO drowsiness classification model
│   └── 📂 roadguardian/         ← RoadGuardian Random Forest models
│       ├── roadguardian_event_status_rf_v2.pkl   ← Predicts NORMAL/WARNING/CRITICAL
│       └── roadguardian_event_type_rf_v1.pkl     ← Predicts event type (COLLISION etc.)
│
├── 📂 input/                    ← Place input videos here

│   └── external_road.mp4        ← Sample road-facing ADAS dashcam video
│
└── 📂 output/                   ← Auto-generated by processing pipelines
    ├── processed_driver.mp4     ← Annotated driver video (H.264)
    ├── processed_road.mp4       ← Labeled road video with bounding boxes & lanes (H.264)
    ├── telemetry.json           ← Driver DMS per-frame metrics
    ├── road_telemetry.json      ← Road ADAS per-frame vehicle counts & distances
    ├── events.json              ← Driver alert state transitions
    ├── road_events.json         ← Road hazard & lane departure events
    └── roadguardian_blackbox_event.csv ← 26-frame EDR accident dump
